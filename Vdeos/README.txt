Показ

В mgts-defense-with-screencasts.pptx все три видео встроены в файл.
Видеослайды размещены сразу после исходного слайда об обзоре программы.
В PPTX заданы автоматический запуск, повтор до смены слайда и отключение
звука. На следующий слайд переходите стрелкой вправо после одной итерации.
Щелчок по видео переключает воспроизведение. Слайды 6–9 продолжают
исходную презентацию. Для отдельной вставки используйте три MP4.

Повторная запись

1. В отдельной чистой копии откройте коммит 3d55187 ветки
   astra/final-delivery, установите зависимости из requirements.txt.
   Выполните python -m scripts.seed_demo. Запустите python app.py
   с PORT=18086. На /health ожидается {"status":"ok"}. В обзоре
   до прогона вебхука должно быть 59 версий анкет.
2. Подготовьте Node.js, Playwright с Chromium и FFmpeg с libx264.
   Из корня репозитория выполните:
       node Vdeos/source/capture.cjs
   Если Node.js не видит Playwright, задайте PLAYWRIGHT_MODULE с путём
   к установленному модулю. При необходимости укажите CHROMIUM_PATH.
   Скрипт содержит хронометраж кадров, траекторию курсора и подписи.
3. Соберите PPTX заново командой:
       python3 Vdeos/source/build_deck.py <путь-к-mgts-internship.pptx>
   Исходный файл берётся из docs/defense/ финальной ветки. Шрифты
   оригинальных слайдов перечислены в docs/defense/README.md.
