# Код города · HR-дашборд МГТС

Flask-дашборд для обратной связи по стажировкам. Показывает охват опросов, изменения оценок за шесть месяцев и расхождения между ответами стажёров и наставников.

Google Forms API получает новые ответы, а openpyxl загружает историю из XLSX. Python связывает анкеты по стажёру, роли и месяцу. SQLite хранит версии. DeepSeek разбирает комментарии, Flask и Jinja строят страницы, Waitress обслуживает запросы.

- [Демо в Docker](docs/run.md#синтетическое-демо-из-чистого-клона) и [импорт исторических анкет](docs/run.md#организаторская-история)
- [Настройка Google Forms](docs/run.md#google-forms) и [DeepSeek](docs/run.md#deepseek)
- [Задание организаторов](docs/task/case.md), [анкета стажёра](docs/task/intern-form.md) и [анкета наставника](docs/task/mentor-form.md)
- [Контракт данных и контрольные числа](docs/09-final-spec-and-data.md)

Для настроек скопируйте [`.env.example`](.env.example) в локальный `.env`. Исходные XLSX и файлы OAuth храните в локальной папке `data/`.
