# Код города · HR-дашборд МГТС

Прототип помогает HR следить за шестимесячной программой стажировок и разбираться в причинах сигналов по каждому стажёру.

## Как это работает

1. `openpyxl` читает историю из двух XLSX. Google Forms собирает новые анкеты стажёров и наставников, а фоновый опрос API с Google OAuth регулярно забирает ответы. Для Яндекс Форм предусмотрен отдельный приём через вебхуки с токеном.
2. Python приводит ответы к общему формату и связывает их по ID стажёра, роли и месяцу. SQLite сохраняет историю версий и отсекает повторную доставку. Для расчётов используется актуальная версия каждой анкеты.
3. Числовые сигналы рассчитывает Python по правилам для низких баллов, падений и расхождений. DeepSeek отдельно разбирает текст, выделяет темы и предлагает действие для HR. Приложение проверяет структуру ответа модели и ссылки на комментарии. Оценки и исходные отзывы доступны при сбое ИИ.
4. Flask формирует обзор и карточки, Jinja рендерит HTML, CSS отвечает за оформление, Waitress обслуживает HTTP. Docker Compose запускает приложение и подключает локальную папку `data/` для хранения истории.

Команды запуска ниже относятся к ветке `team/dashboard-polish`. При объединении изменений проверяйте основной сценарий на итоговой ветке.

Исходные XLSX и выгрузки храните локально в `data/`. Ключи провайдеров передавайте приложению через переменные окружения.

## Подготовить исторические анкеты

Для запуска с Docker положите две книги в `data/intern.xlsx` и `data/mentor.xlsx`, затем выполните `docker compose up --build`. Откройте [стартовую страницу](http://127.0.0.1:8080/start) или [дашборд](http://127.0.0.1:8080). [Запуск без датасета и настройка внешних сервисов](docs/run.md).

```powershell
py -m pip install -r requirements-import.txt
py scripts/import_history.py --intern data/intern.xlsx --mentor data/mentor.xlsx --verify-case
```

Подставьте пути к выданным книгам. Команда проверяет поля, оценки, периоды и повтор строк внутри каждой роли, затем сохраняет `data/history.json`. Это первичная загрузка истории. Автоматический приём из форм подключается к тому же контракту отдельным адаптером.
