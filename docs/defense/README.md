# Защита проекта «Код города»

## Выступление на 3 минуты 45 секунд

| Время | Что сказать и показать |
|---|---|
| 0:00–0:25 | **Слайд 1.** «Каждый месяц стажёр и наставник описывают одну стажировку с разных сторон. Куратору нужно найти случай, который стоит обсудить, и понять, о чём спросить». Уточнить, что все показанные ответы синтетические. |
| 0:25–0:55 | **Слайд 2 и обзор.** Открыть месяц 6 и карточку DEMO-2. Стажёр оценивает понятность задач на 2, наставник оценивает понимание задач на 4. Низкая оценка вместе с разницей в 2 балла даёт критичный сигнал. Для DEMO-3 отсутствует анкета наставника. |
| 0:55–1:40 | **Слайд 3 и приложение.** На чистом демонстрационном наборе выполнить команду отправки из инструкции запуска. Скрипт имитирует две отправки через локальный вебхук. Обновить обзор. Показать, как охват наставников за месяц вырос с 4/5 до 5/5, а история с 59 до 61 версии. Повторить команду: оба ответа получают статус `duplicate`. |
| 1:40–2:25 | **Слайд 4 и карточка.** Вернуться к DEMO-2, раскрыть шестой месяц. Показать 1 и 4, разницу +3 и текст «критерии приёмки всё ещё неясны». В пятом месяце стажёр писал о критериях готовности. Возможный шаг HR — разобрать с обеими сторонами один пример готовой задачи. Это предложение для обсуждения с куратором. |
| 2:25–3:15 | **Слайд 5.** Google Forms требует настройки владельца. В показанном прогоне запросы поступили через локальный вебхук. Flask сохраняет версии в SQLite. Код рассчитывает числовой сигнал. При подключении DeepSeek модель получает разрешённые фрагменты, а приложение проверяет ссылки на них. Для оценки пользы провести с кураторами разбор одного набора вручную и в прототипе, записать время и полезность сигналов. |
| 3:15–3:45 | **Слайд 6.** Открыть ссылку на инструкцию запуска и назвать условия живого показа: владелец авторизует формы, разрешает публикацию и отправляет тестовые анкеты. Для живого анализа требуется ключ DeepSeek и разрешение на передачу соответствующих комментариев. |

## Резервный показ на 45 секунд

Держите PDF открытым рядом с приложением. На слайде 2 покажите исходные оценки 2 и 4. На слайде 3 покажите снимки обзора до и после приёма двух анкет через локальный вебхук. На слайде 4 прочитайте фрагмент стажёра, укажите итоговую разницу +3 и сформулируйте вопрос к наставнику. При отсутствии сети этот маршрут полностью доступен из PDF.

## Перед выходом

- Для живого показа откройте обзор у блока «Источники данных» и одну Google Form в соседней вкладке. Отправьте маркированный тестовый ответ для участника из справочника, вернитесь к обзору и после очередной проверки API обновите страницу. Покажите счётчик роли, затем карточку выбранного месяца с источником «Google Forms». Используйте отдельную демонстрационную базу или согласованный тестовый ответ.

- Запустить прототип заранее по инструкции из репозитория. Для повторной репетиции с исходными показателями подготовить отдельную пустую папку синтетических данных. Повторная отправка в прежнюю базу проверяет защиту от дублей.
- Для редактирования PPTX в фирменном оформлении установить из [брендбука МГТС](https://disk.yandex.ru/d/uXw7Qs1IOmeFAg) шрифты MTS Extended Black, MTS Text Regular и MTS Text Medium. Оформление сверено с разделами «Цвет презентаций», «Логотип МГТС» и «Шрифт». Для показа на чужом компьютере используйте PDF.
- Уточнить у организаторов лимит выступления и окно загрузки. Репозиторий содержит ориентиры на 4 минуты защиты и 2 минуты вопросов, а также сокращённую трёхминутную версию. Для трёх минут убрать повторную отправку из живого показа и сократить объяснение архитектуры.

## Что проверено и что остаётся капитану

Docker собран, контейнер отвечает на `/health`. Синтетический прогон добавил две версии (59 → 61), закрыл пропуск и сохранил результат при повторной доставке и перезапуске. В браузере проверены фильтры, карточка на шесть периодов и вид при ширине 390 пикселей. Восемь автоматических тестов прошли, включая фоновое получение ответов Google API в тесте и проверку оснований, редактирования и обработки таймаута DeepSeek.

Исходные книги организаторов сверены: 30 анкет стажёров, 30 анкет наставников, 30 пар. Отдельный живой прогон с обеими Google Forms добавил две маркированные тестовые анкеты к исторической базе. В шестом месяце записи СТ-005 отобразились оценки 1 и 4, разница +3 и источник Google Forms. После перезапуска в базе 62 версии. Слайды описывают резервный сценарий на синтетической истории с локальным вебхуком.

Прямой запрос к DeepSeek с новым ключом прошёл. Перед показом прогоните анализ синтетического отзыва через дашборд и откройте результат с основаниями в карточке. Отправка исторических комментариев требует подтверждения владельца данных.
